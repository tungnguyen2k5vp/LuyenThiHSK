# 4Chinese web learning area

Open `/` for learning. Existing `?view=...`, `?session=...`, `?attempt=...` and `/admin` paths still open the HSK application. Exam code, question banks, content SQLite and previous learning storage are not modified by the new learning area.

## Reused from the source app

- `src/chinese/reused/`: app scheduler, vocabulary corrections, identity/matching, topic classifier, local-calendar statistics, study-time tracker and community API/schema. Source hashes are in `public/data/fourchinese/reused-source.json`. Changes to imports and ES2020 array access are web compatibility adjustments.
- `scripts/import-fourchinese.mjs`: reproduces `getOfflineVocabulary`'s merge order, explicit corrections and deduplication. Reads `../HocTiengTrungApp/src/data` without writing there. Matches the 2025 syllabus using the app's headword/reading/POS matcher. Existing web example MP3 files are referenced, not copied again.
- Published library: 11,870 dictionary entries; 68 with Vietnamese starter examples; 4,471 with existing recorded examples. 9,438 of the 11,000 official 2025 rows match the app dictionary; 1,562 remain unresolved. The dictionary's older bands are labelled separately. These figures are dictionary content, not learner progress.
- Community uses the app's existing Supabase RPCs and validation. Only the app's public endpoint and public anonymous key are configured in the ignored `.env.local`; no database migrations, service-role keys or app sessions are copied.

## Working flows

New words: visible model → recognition → Hanzi composition; completion is saved only after the third correct pass. Known/skipped words stay separate. Review starts thirty minutes later and uses the original six memory levels. Incorrect answers can return once; that retry and early practice do not update the schedule twice. The selected word/pass and review feedback survive reload.

Personal decks reference canonical IDs and share one schedule per word. The web records actual completed actions, answer results and foreground study time. The timer pauses when hidden or idle for ninety seconds. Statistics include memory levels, accuracy, skill history, daily activity and streaks. Backups are validated before restoring, with a copy retained before replacement. Invalid existing storage is not silently overwritten.

Community supports the real feed, filtering/search, text posts, bookmarks/reactions/comments, friend lookup/acceptance and text messages. Unsent post/message drafts and retry IDs are stored locally by community identity. It connects only when the learner chooses the connection button. Web community identity is separate from the app session; learning progress is not cloud-synced by this implementation. Attachments remain available in the mobile app. No live community content was posted during verification.

## Run and check

```powershell
npm run dev
npm run server
npm run account:server
npm run test:4chinese
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
npm run test:browser:4chinese
```

Browser checks use the already installed REA `playwright-core`, Chrome in the standard Windows installation, isolated browser storage and mocked community endpoints. Set `HSK_WEB_URL` to test another local port. They cover three-pass completion, reload/resume, decks, review/retry, mobile overflow, pinyin search, community RPC rendering and the legacy exam route. Screenshots: `4chinese-web-desktop.png`, `4chinese-web-mobile.png`.

The Vite dependency scan is limited to `index.html`; historical `.tmp` copies are not dependency entry points. No new regression workspaces or audio copies are generated by these checks.
